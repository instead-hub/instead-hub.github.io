INSTEAD 3.6.0


Опубликовано 27.09.2026

После долгого перерыва выпущен INSTEAD 3.6.0!

В этот раз обновление очень объёмное. INSTEAD переписан для работы с SDL3. Это дало возможность ещё упростить код и облегчить его сопровождение в будущем. Библиотеки SDL3 пока только появляются в дистрибутивах Linux, поэтому самостоятельная сборка скорее всего потребует сборки этих библиотек вручную.

Для сборки на старых системах сохранена ветка SDL2.

Список основных изменений:

  • переход на SDL3;
  • исправлено большое число ошибок;
  • почищен код от старых платформ;
  • убрана зависимость от GTK;
  • обновлена сборка emscripten;
  • сборка macOS версии на github раннерах.

Бинарные сборки будут появляться по мере готовности.
