INSTEAD 3.6.0


Posted 27.09.2026

After a long delay, INSTEAD 3.6.0 has been released!

This is a major update. INSTEAD has been rewritten to work with SDL3. This has made it possible to further simplify the code and make future maintenance easier. Since SDL3 libraries are only just starting to appear in Linux distributions, building from source will likely require compiling these libraries manually.

The SDL2 branch has been retained for builds on older systems.

Key changes:

  • migration to SDL3;
  • numerous bug fixes;
  • code cleanup (removal of legacy platform support);
  • removal of the GTK dependency;
  • updated Emscripten build;
  • macOS builds via GitHub Runners.

Binary builds will be released as they become ready.

Stay tuned!
